# Fitness Tracker Microservices

A fitness management platform built using Spring Boot Microservices.

## Services

- User Service
- Activity Service
- AI Service
- Eureka Discovery Server

## Tech Stack

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- MongoDB
- Apache Kafka
- Eureka Service Discovery

## Upcoming Features

- API Gateway
- JWT Authentication
- Redis
- Config Server
- Docker
